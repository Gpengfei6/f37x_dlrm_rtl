# Stage-2A Vivado 2020.2/XSim validation handoff

This payload is credential-free and does not contain `.git`.  Run it only on the
user-controlled validation server.  Codex does not access the server.

From the extracted `f37x_dlrm_rtl` directory, the minimum ordered command is:

```bash
python3 scripts/run_python_tests.py && \
python3 scripts/run_stage2a_python_tests.py && \
vivado -mode batch -nojournal -nolog -source scripts/run_xsim_stage1.tcl && \
vivado -mode batch -nojournal -nolog -source scripts/run_xsim_stage2a.tcl && \
python3 scripts/collect_validation_bundle.py --collect-logs --stage2a
```

Return these files without editing them:

- `results/stage2a_validation_logs.zip`
- `results/validation_summary.json` when generated by the outer workflow
- `results/xsim_stage1_status.txt`
- `results/xsim_stage2a_status.txt`
- `results/source_manifest_sha256.json`

Acceptance requires the Stage-1 regression to remain PASS, all six Stage-2A
testbenches to compile/elaborate/simulate with their explicit PASS markers, the
Python Stage-2A summary to be PASS, and all source hashes to match the payload
manifest.  Exit code zero without a PASS marker is not sufficient.
