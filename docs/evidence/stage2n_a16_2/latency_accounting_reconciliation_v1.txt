The residual is an algebraic interval remainder. It is not an independently
instrumented pipeline stage and must not be interpreted as physical HBM
latency, Host time, or a performance result.

The A16.1 testbench deliberately performs AXI-Lite observation and stress
transactions between accepted A15 START and the first AR handshake: it reads
the A15 status after START, reads the embedding mask while ARVALID is held,
holds ARREADY low for four rising edges, and on slot 0 issues a repeated START,
reads the resulting error, and acknowledges that error before releasing
ARREADY. Those cycles are inside FPGA_END_TO_END_CYCLES but before the start of
HBM_LOOKUP_CYCLES. The physical Host does not inject that testbench-only
pre-first-AR stress sequence; after START it polls for the final result.

After the first AR handshake, the local fake-memory service routine also uses
deliberate ARREADY/RVALID delays and AXI-Lite mask polling. The physical target
instead contains the real shell, interconnect, HBM controller, and HBM service
interval. Therefore a longer physical HBM interval and a shorter interval
remainder can coexist. Numerically, +39 lookup cycles and -35 remainder cycles
produce the observed +4 end-to-end cycles while the accepted compute interval
remains exactly 1174 cycles.
