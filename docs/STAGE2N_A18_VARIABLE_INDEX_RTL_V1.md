## Register map

A2 `0x000-0x17F` unchanged. A13 through `0x224` unchanged. A15/A16/A17
BASE and counters `0x300-0x32C` unchanged.

| Address | Access | Meaning |
|---|---|---|
| `0x180-0x224` | as A13 | control, result, A13 cycle counters |
| `0x184` | R | pipeline version `0x00024E18` |
| `0x300` | R/W command | START=`0x1`, CLEAR=`0x2`; status bits as A17 |
| `0x304/0x308` | R/W while IDLE | BASE0 low/high |
| `0x30C` | R | lookup cycles |
| `0x310` | R | FPGA end-to-end cycles |
| `0x314` | R; writes rejected | reserved, reads 0 |
| `0x318/0x31C` | R/W while IDLE | BASE1 low/high |
| `0x320/0x324` | R/W while IDLE | BASE2 low/high |
| `0x328/0x32C` | R/W while IDLE | BASE3 low/high |
| **`0x330`** | R/W staging | **lookup index slot 0** |
| **`0x334`** | R/W staging | **lookup index slot 1** |
| **`0x338`** | R/W staging | **lookup index slot 2** |
| **`0x33C`** | R/W staging | **lookup index slot 3** |

Reset defaults: slot0=37, slot1=38, slot2=39, slot3=40. Packed
`{40,39,38,37}` is **not** the software slot order; LSB slot0 is 37.

`0x300` status bits are the accepted A17 word, including `[4]` DONE,
`[5]` error, `[6]` start-ready, `[30:28]` sequencer state.

Wrapper error codes are the A17 codes: busy BASE=`4'd1`, bad command=`4'd2`,
core not ready / repeat START / illegal CLEAR=`4'd3`, bad address=`4'd4`,
host embedding=`4'd5`.

## Latch, busy-write, CLEAR, OOB

- Four indexes and four table bases latch together on an **accepted START**
  from IDLE.
- **Busy index writes** (`0x330-0x33C` while not IDLE) are **ignored**. No
  wrapper error. Reads still return staging values.
- **Busy BASE writes** still raise `WRAPPER_ERROR_PENDING` (`4'd1`).
- **Repeat START** while not ready still raises `WRAPPER_ERROR_CORE_NOT_READY`
  (`4'd3`).
- **CLEAR** matches A17: legal only from **DONE → IDLE** and **ERROR →
  RECOVER**. CLEAR from LOAD/PIPE is rejected (`4'd3`). The earlier draft
  that accepted CLEAR from LOAD/PIPE is **withdrawn**.
- **OOB:** any latched index `>= 64`, including `0xFFFFFFFF`, issues **no
  ARVALID** on any master. The A18 integration raises the existing HBM
  sequence-error handshake. No truncate, modulo, or clamp.
