## 本轮核对过的原文

- UCNN（ISCA 2018，arXiv:1804.06508）：重复权重做点积因式分解，再做激活组复用。索引表是成本的一部分。后续对全连接的讨论指出，索引宽度可以吃掉乘法节省。重复、精确、少做乘法这三个词不够。
- FlowTT（arXiv:2609.03459，2026-09 预印本）：TT embedding 里共享高位前缀的收缩，中间量留在片上。评测是 GPU、batch 32768。它否定“发现重建里的公共前缀再共享”这个泛化说法，不是我们的冻结稠密表。
- RecJPQPrune（SIGIR 2025，arXiv:2505.00560）：safe-up-to-rank-K，对象是 RecJPQ 子项分数。
- ProactivePIM（IEEE Access 2025）：QR-trick / TT-Rec 的重建和额外通信要计费。
- 出版商条目 `10.1016/j.aeue.2026.156548` 这次打开失败（HTTP 406）。附近的 arXiv:2608.06177 是二值激活的阈值早停，并允许精度下降，不是 INT16 逐位证书。C 不靠这句判死，也不靠它重开。

nMARS 正文、Rare Computing 全文、VecMADS、HeteroRec 和各学位论文本轮没有逐段复核。不用“全部封死”代替这些未读部分。
