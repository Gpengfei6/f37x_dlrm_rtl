## A16.2 MEM_TOPOLOGY context (imported evidence)

The accepted A16.2 xclbin already enumerates `HBM[0]` through `HBM[31]`. In
that artifact:

- topology index 0 is `HBM[0]`, `m_used=1`;
- indexes 1, 2, 3 are `HBM[1]`, `HBM[2]`, `HBM[3]`, `m_used=0`.

That listing proves the platform **tags** exist. It does not prove an A17
four-bank link or that a future xclbin will keep the same indexes. Host code
must resolve group/mem index from `m_tag`, not from the bank number.
